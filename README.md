## 🏢 Professional work

### QuantumNova

At QuantumNova, I contribute across multiple products in the company ecosystem, mainly focused on frontend development, product interfaces and cross-platform client experiences.

Some of the main areas I have worked on include:

---

### 🛡️ QSWAN — Post-Quantum Private Network Management

QSWAN is a management platform for private post-quantum-safe networking, focused on gateway creation, gateway-to-gateway connections, routing/rules management, user access and profile distribution.

I worked mainly on the **React frontend**, building interfaces for complex network and user-management workflows.

**Key areas I worked on:**

- Gateway creation and management
- Connections and rules between gateways
- User and profile management
- Certificate/profile distribution flows between server and client
- Dashboards with charts, tables and operational data
- Responsive UI for desktop and mobile usage
- Frontend integration with a Python backend

**Tech:** React, JavaScript/TypeScript, Python backend integration, REST APIs, charts, responsive UI

---

### 🖥️ QNova Client — Desktop Application

QNova Client is the desktop client used to connect to private gateways and manage user profiles.

The main Windows version is an **Electron application** with a React frontend and native backend components using Python and C, communicating through IPC and WebSockets.

**Key areas I worked on:**

- React frontend for the desktop client
- IPC and WebSocket-based communication flows
- Multiple profile management
- Gateway/client connection flows
- Quantum-safe peer-to-peer file transfer interfaces
- Drive access features linked to managed gateways
- UI adaptation for macOS support
- Custom installer work, including Tauri-based installer experimentation

**Tech:** Electron, React, JavaScript/TypeScript, Python, C integration, IPC, WebSockets, Tauri

---

### 📱 QNova Client — Android

I independently built the Android version of QNova Client, focused on connection and profile management.

The Android app includes profile handling, connection flows and MFA using QR Code authentication, and is currently available on the Google Play Store.
